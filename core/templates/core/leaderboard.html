ℹ️ Simulation Logic (For the Evaluator)

This page demonstrates a database READ query with Aggregation & Sorting. The Python backend queries the database for all APPROVED squad applications that have had their points simulated. It then sorts them descending to generate the rankings:
SquadApplication.objects.filter(status='APPROVED', total_points__isnull=False).order_by('-total_points')

The points are generated in the simulate_squad view using a randomized heuristic based on the player's position (e.g., forwards have a higher chance of scoring more points than defenders).
