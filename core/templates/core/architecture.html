System Architecture Pipeline

Visualizing the automated backend data flow from the PostgreSQL/SQLite Database to the User Interface.

IDLE

🗄️ 1. Database Query Engine

Function: Scans the database for active Fantasy Teams, current player rosters, and impending Gameweek fixtures. Locks the state for processing.

IDLE

⚙️ 2. Match Simulation Engine

Function: The core logic layer. Executes complex probability algorithms to simulate match outcomes, calculating random variables for goals, assists, and clean sheets.

IDLE

🧮 3. Allocation Matrix

Function: Translates raw match events into Fantasy Points. Applies business rules (e.g., Captaincy 2x multiplier, position-based scoring variations).

IDLE

🖥️ 4. View Rendering

Function: Commits all calculated data to the database, breaks the browser cache, and dynamically populates the HTML templates with the new leaderboards.
